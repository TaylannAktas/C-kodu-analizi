# C-kodu-analizi
LevelUp için C kodu analizi yapıyoruz

## Birlikte geliştirme ortamı

Arkadaşlarınızla aynı projeyi ortak bir ortamda geliştirmek için bu depo **GitHub Codespaces + Dev Container** ile hazırlandı.

### Kurulum
1. GitHub'da bu depoyu açın.
2. **Code** > **Codespaces** > **Create codespace on main** adımlarını izleyin.
3. Ortam açıldığında herkes aynı geliştirme araçlarıyla çalışır.

### Takım akışı (önerilen)
1. Her geliştirici kendi branch'ini açar.
2. Değişiklikler commit edilip pull request ile gönderilir.
3. Kod inceleme sonrası main branch'e birleştirilir.
